# Security

Please report vulnerabilities privately to hello@nodrail.com, with steps to reproduce. Do not open a public issue.

Include the version, the rules involved, and the call that got the wrong outcome.

Fixes go to the latest release. The [security model](docs/security-model.md) describes what the engine does and doesn't guarantee; limits listed there aren't vulnerabilities, but we'd still like to hear about ways to make them smaller.

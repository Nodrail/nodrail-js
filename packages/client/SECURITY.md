# Security

Please report vulnerabilities privately, through
[GitHub's private reporting](https://github.com/Nodrail/nodrail-js/security/advisories/new)
or to hello@nodrail.com, with steps to reproduce. Do not open a public issue.

Most useful: a way to make a governed tool run without an exact allow, a hook
that lets a call through when it should block, or a secret that reaches Nodrail
unredacted. Include the version, the framework, and the call.

Fixes go to the latest release. The README's **Limits** and **What guard can't
cover** sections list what the client doesn't protect against; those aren't
vulnerabilities, but we'd still like to hear about ways to make them smaller.

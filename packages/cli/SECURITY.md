# Security

Please report vulnerabilities privately, through
[GitHub's private reporting](https://github.com/Nodrail/nodrail-js/security/advisories/new)
or to hello@nodrail.com, with steps to reproduce. Do not open a public issue.

Most useful: a way to make the command decide or publish without a person
confirming, a token written somewhere other people can read, or a token sent
anywhere but the Nodrail address you chose. Include the version and the
command.

Fixes go to the latest release.
